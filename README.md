# VK OTO ÇÖZÜM

Volkan Kaya'nın oto servisi **VK OTO ÇÖZÜM** için kurumsal tanıtım web sitesi.
Sincan / Ankara'da AdBlue, EGR, DPF, DTC, klima gazı, kalorifer petek temizliği,

| Sayfa | Dosya |
| --- | --- |
| Ana Sayfa | `index.html` |
| Hizmetler | `hizmetler.html` |
